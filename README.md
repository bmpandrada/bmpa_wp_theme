# BMPA WordPress Custom Theme ☕️

A custom WordPress theme built from scratch using PHP, ACF, Bootstrap, SCSS, and modern WordPress best practices.

## ✨ Features
- Custom WordPress theme (no page builder)
- Modular structure using `template-parts`
- Advanced Custom Fields (ACF) for dynamic content
- Reusable sections (Hero, About, Services, Testimonials)
- SCSS compiled to CSS
- Responsive layout using Bootstrap
- Clean Git workflow

## 🧩 Technologies Used
- WordPress
- PHP
- Advanced Custom Fields (ACF)
- Bootstrap 4
- SCSS (Sass)
- jQuery
- Git & GitHub
